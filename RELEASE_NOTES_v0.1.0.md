# Изи Хост v0.1.0 — Release notes

## Исправлено
- Кнопки действий выровнены в две строки с одинаковой высотой.
- Добавлены пиктограммы для запуска, остановки, браузера и копирования.
- Добавлено открытие сайта на `127.0.0.1`.
- Добавлено копирование LAN-ссылки и показ IP-адреса Wi-Fi.
- Сохранение папки, выбранного проекта и порта.
- Большие файлы отдаются потоково.
- Добавлена базовая фильтрация опасных сегментов URL-пути.

## Не включено в этот релиз
PHP runtime, WebSocket чат-сервис и Android Foreground Service. Эти функции нельзя честно считать готовыми: им нужны нативная сборка/интеграция и отдельные проверки на устройстве. В README описаны требования и текущие ограничения.
