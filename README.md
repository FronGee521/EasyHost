# Изи Хост (EasyHost) — 1.2.0

Android-приложение для запуска локальных статических сайтов на телефоне.

## Реализовано в этой версии
- Брендинг «Изи Хост» и launcher icon из предоставленного изображения.
- Сохранение выбранной корневой папки, проекта и порта.
- Восстановление постоянного разрешения SAF при повторном запуске.
- Запуск сервера через Android Foreground Service с постоянным уведомлением и действием «Остановить».
- Запуск NanoHTTPD вне UI-потока.
- Быстрые действия: открыть `http://127.0.0.1:<порт>` в браузере и скопировать адрес.
- Потоковая отдача файлов вместо предварительной загрузки всего файла в память.

## Сборка
Откройте `EasyHost-main` в Android Studio с JDK 17. В проекте нет Gradle Wrapper; используйте установленный Gradle 8.9 или добавьте wrapper из Android Studio. Соберите через Build > Build APK(s).

## Ограничения
- Поддерживается статическая раздача HTML/CSS/JS и других файлов. PHP-код не исполняется — PHP runtime в проект не включён.
- Адрес `127.0.0.1` доступен только на самом телефоне. Для доступа с других устройств в локальной сети нужен LAN IP телефона; в этой версии действие копирования предназначено для loopback URL.
- Foreground Service повышает устойчивость работы в фоне, но не гарантирует работу при принудительной остановке приложения, перезагрузке телефона или ограничениях прошивки.
- Для Android 14+ используется тип Foreground Service `specialUse`; фактическая политика распространения в Google Play требует отдельной проверки.
